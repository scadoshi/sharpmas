# 2026-08-23

The Filter port landed, written on the plane to London from the banked plan.
Everything on the smaller list went with it, so the rustmas catch-up is done.

- **`Filter` in `Domain/Address/`**, a validated type with a plain constructor
  rather than a `New` factory, since C# constructors are the idiom. Four cases
  in a tuple switch; the pair case proves itself through the `Day` constructor
  and keeps the parts.
- **Guard messages stayed the C# dialect.** `ThrowIfGreaterThan(day,
  year.DaysIn(), nameof(day))` already names the value and the live bound:
  `day ('13') must be less than or equal to '12'`. Not rustmas's `1..=12`
  phrasing, and not worth fighting the analyzer for. Tests assert the values
  rather than the range spelling.
- **`Day.All()` then `Day.Matching(filter)`**, with `Each` deleted. Two bugs on
  the way, both caught by the mirrored tests before any run: `Enumerable.Range`
  takes a count rather than an end, the same trap the 2026-08-07 entry
  recorded, and the inner range used `FinalDay` where 2025 needed
  `year.DaysIn()`.
- **`HasSecondPuzzle` wired into `EnsureEntry`'s gate**, so a finished day 25
  stops costing a request every run.
- **`Answer.Unwritten`** as its own case, in the template stubs too, so a stub
  cannot read as a finished part with nothing to say.
- **The four hierarchies closed** with private base constructors: only nested
  types can inherit, which is as near as C# gets to a sealed sum.

Also restructured this journal into one file per day, and the plans directory
emptied back into here as each plan finished.
